\section{Example Test Cases}
\label{app:example-tests}

This appendix provides example test cases in a structured format suitable for automated evaluation pipelines. Adapt these templates to your application.

\subsection{Test Case Format}

Each test case should include:
\begin{itemize}
    \item \textbf{ID:} Unique identifier for tracking.
    \item \textbf{Category:} Classification (e.g., ``happy path,'' ``edge case,'' ``adversarial'').
    \item \textbf{Input:} The query or prompt sent to the LLM.
    \item \textbf{Context:} (For RAG) Retrieved documents or provided context.
    \item \textbf{Expected Output:} Reference answer or criteria for correct answers.
    \item \textbf{Assertions:} Automated checks to apply.
    \item \textbf{Rubric Dimensions:} Which human evaluation rubrics apply.
\end{itemize}

\subsection{JSON Test Case Format}

For integration with evaluation harnesses, use structured formats:

\begin{lstlisting}[basicstyle=\small\ttfamily, frame=single, caption={Example JSON test case.}]
{
  "id": "CS-001",
  "category": "happy_path",
  "input": "How do I return an item I bought last week?",
  "context": null,
  "expected_output": {
    "reference_answer": "To return an item, visit...",
    "acceptable_keywords": ["return", "refund", "policy"],
    "unacceptable_keywords": ["cannot", "impossible"]
  },
  "assertions": [
    {"type": "contains_any", "values": ["return", "refund"]},
    {"type": "max_length", "value": 500}
  ],
  "rubric_dimensions": ["helpfulness", "accuracy"],
  "metadata": {
    "priority": "high",
    "author": "qa_team",
    "created": "2025-01-15"
  }
}
\end{lstlisting}

\subsection{Adversarial Test Categories}

Include tests from each adversarial category:

\begin{enumerate}
    \item \textbf{Prompt injection:} Attempts to override system instructions.
    \item \textbf{Jailbreaking:} Attempts to bypass safety guardrails.
    \item \textbf{Information extraction:} Attempts to elicit confidential data.
    \item \textbf{Confusion attacks:} Contradictory or malformed inputs.
    \item \textbf{Denial of service:} Extremely long or nested inputs.
\end{enumerate}

Document the expected behavior (typically: refuse politely, do not comply) and assertions for each.
